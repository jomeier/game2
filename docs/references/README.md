# Art references

Reference screenshots from shipped 2D platformers. The research fed `DG-P-10`
and `DG-P-11`. These files are research material only. Nothing from other games
ships in `src/`.

The folder is the same set as in `game1`, because both games follow the same art
decisions.

Each row names the lesson the project takes from the image. The images come
from the official Steam store pages of each game.
